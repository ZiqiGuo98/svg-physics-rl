球撞墙:模型不借助代码,能否逐帧画出正确的碰撞过程?

任务:模型直接输出逐帧静态 SVG;评分器按 id 抽取球的坐标,先检查硬约束(穿墙等),再比较软精度(撞墙时刻、反弹速度比、轨迹)。

2. 任务与评分设置

任务:球从左侧出发,水平匀速向右,撞到右侧的墙后反弹,恢复系数为 e。题目给出初速度 v、墙的位置、球半径、e、帧间隔 Δt 和画布比例尺;模型画 16 帧。每道题随机化 v、e、墙的位置、球半径,并满足:e ∈ [0.3, 0.95];接触前后各至少 4 帧;反弹后终点仍在画布内;撞墙时刻不落在采样帧上(误差 ±0.1Δt 内)。

标准答案(评分端计算):撞墙前 x = x₀ + v·t;球表面碰到墙的瞬间速度变为 −e·v。

坐标约定:用球的圆心 cx;题目给出的是墙内侧面的 x,圆心距墙面等于半径 r 时为接触。墙的位置和球半径一律取题目参数,评分器不读 SVG 里的值,只检查 SVG 里的值与参数一致(±1px),不一致算格式失败;球的 y 应保持恒定。解析只认 circle#ball,其余元素不参与评分。

三个量怎么在离散帧上定义

  • 入射速度:对接触前的帧做最小二乘直线拟合,取斜率。
  • 反弹速度:对接触后的帧做同样的拟合,取斜率。
  • 模型的接触时刻:两条拟合直线与 x = x_墙 − r 的交点。不用"最靠近墙的那一帧"。
  • 诊断量:单独记录"第一帧反弹后的位置误差",它最能区分 e=1 的镜像反射和真正按 e 反弹。

奖励:硬约束 + 软精度的字典序

格式不对:            reward = 0
违反任一硬约束:      reward = 0.2 × soft        (最高 0.2)
满足全部硬约束:      reward = 0.3 + 0.7 × soft  (最低 0.3)

soft ∈ [0,1],由撞墙时刻、反弹速度比、轨迹偏差三项算出(取几何平均或最小值),
每项带容差带:误差在容差内记满分,超出才衰减。

硬约束(任一违反即进入违规层):穿墙(任一帧球表面越过墙面超过容差);未到墙就掉头(最大 x 比标准答案在采样帧上的最大 x 小超过 0.5·v·Δt);撞墙后按自身轨迹的方向没有反向;反弹速度大于入射速度的 1.05 倍;帧间位移超过 1.5·v·Δt、y 漂移、出画布、全程静止。

成功(训练前固定):无硬约束违规,且撞墙时刻、反弹速度比、轨迹三项全部在容差内。由于容差内记满分,成功等价于 reward 恰好为 1.0:成功率是 reward 的阈值化,不是独立于 reward 的证据。独立验证需要另加人工或 VLM 抽查视频,或第二份独立实现的评分器。

容差的设定顺序:先定物理容差(如 e 的相对误差 10%、接触时刻 ±0.25Δt),再由它们推导轨迹容差,避免三项容差互相矛盾。

失败类别(互斥,按优先级从上到下判定)

类别判定属于
格式失败帧数不对、缺 id、有禁用元素、墙或半径与参数不一致、解析失败格式
瞬移/越界/不动帧间位移超过 1.5·v·Δt、y 漂移、出画布、全程静止硬约束
穿墙任一帧球表面越过墙面超过容差硬约束
未到墙或未反弹没到墙就掉头;或按自身轨迹的方向撞墙后没有反向硬约束
能量增加反弹速度大于入射速度的 1.05 倍硬约束
撞墙时刻偏差超出容差软精度
反弹速度比偏差与 e 的相对误差超出容差(如 e=1)软精度
轨迹偏差其余通过,但整体轨迹超出容差软精度
成功以上全部通过—

"瞬移/不动"排在前面,是因为乱跳的输出会让反弹速度的估计失真,否则会被误归为"能量增加"。

6. 相关工作与讨论

相关工作与定位(部分未核实)

  • SimuScene(arXiv 2602.10840):模型写代码,VLM 看视频判定性问题,GRPO 训练。本工作不同于它的地方是:模型直接输出逐帧状态而非代码;奖励由确定性评分器给出。
  • VisPhyWorld(2602.13294):已核对正文。SVG 与 Manim 仅在 Figure 1 和第 3.4 节被定性提及,称为"基于脚本的后端";论文没有说明其输出是代码还是直接的 SVG 标记,也没有 SVG 的定量结果,主实验只评测 Three.js 与 P5.js。因此无法据此判断"直接画 SVG"是否已有人做过,本工作不据此宣称新颖性。
  • RL with Verifiable Physics(2607.10474)、SVG-LLMs 多奖励 RL(2603.16189)、GAUGE(2608.05948):只读了搜索摘要,未读正文,需核实是否与本工作冲突。
  • 定位:无代码、直接输出状态设定下,用确定性评分器做 RLVR 的小规模可行性演示。不声称"首个"。
  • 一维场景下 SVG 只是坐标的包装,等价于输出一个坐标列表(如 {"ball_x":[…]})。SVG 的价值在于可直接合成视频做人工或 VLM 交叉验证,并能扩展到多物体。SVG 与坐标列表的差异未做对照实验(局限,记为下一步):同题、同评分器,只改输出格式,比较成功率和格式失败率。

讨论

  • 能说明什么:在受控的球撞墙场景里,模型直接输出状态的物理一致性如何;RL 能否降低严重违规并提高成功率,以及提升是否迁移到留出参数。
  • 不能说明什么:不能证明"物理理解";题目给了 v、e、x₀、Δt,答案是闭式公式;场景理想化(单球、刚性墙、无噪声),不能推广到真实视频。
  • 局限:题型少;硬约束与软精度的划分、容差大小是人为设定的;成功等价于 reward=1.0,不是独立证据;留出变体未做;SVG 与坐标列表的对照未做。
  • 需要继续核实:评分器自检(表 2、表 3)的实际结果;连续奖励与二元奖励的对比消融;reward 上升而成功率不涨时的诊断(看图 4)。
